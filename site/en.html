01 / INPUT FORMATS

Different formats. One pipeline.

Parsers understand file formats.
Strategies handle content boundaries.

File formatExtractionSource location
TTXT / MarkdownUTF-8 text, headings, paragraphs and fenced codeOriginal character offsets
PPDFExisting text layer, extracted page by pagePage number
WWord · DOCXBody text, headings, tables and nested table textBody element index / table row
XExcel · XLSXAll worksheets, cells and formula textWorksheet / row and column / cell coordinates

Scanned PDF OCR, legacy .doc / .xls and complex PDF table reconstruction are not supported. Excel formulas are preserved as text, without evaluation.See full scope ↗

A

Replaceable strategies

fixed provides character windows. recursive prefers Chinese and English sentence boundaries, then whitespace between words, with character splitting as a fallback. Mixed content needs no language setting.

B

Validation throughout

Validate lengths, ordering, reference ranges and text reconstruction. Identical inputs and component settings produce identical document and chunk IDs.

C

Independent export

The Python API returns results before you decide whether to write files. Export JSON / JSONL without a vector database dependency.

04 / GET STARTED

Your first document.
Ready to chunk.

Clone the repository and install format dependencies.
Use the same command for all five formats.

Read the installation guide ↗
Python 3.11+ · Use a virtual environment
git clone https://github.com/Chainsy3/universal-rag-chunker.git
cd universal-rag-chunker
python -m pip install ".[all]"
urc chunk examples/guide.md --output out
urc validate out/document.ir.json --chunks out/chunks.jsonl

Individual extras: .[pdf], .[word], .[excel]
