# Contributing

Use Python 3.11+, install the package, and run the unittest suite before proposing changes. Add regression tests for source loss, malformed input, and size or ordering failures. Keep examples original and free of private business documents.

Keep parsers domain-neutral. Add domain-specific behavior through explicit plugins. Changes to normalization, segmentation, or IDs require version and migration notes. Never describe an unsupported format as implemented.

Contributions are made under the project's MIT license. No third-party documents or private business materials are included as fixtures.
